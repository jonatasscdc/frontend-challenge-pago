# 🌟 Minha Agenda de Endereços - Versão Moderna

Uma aplicação React moderna e profissional para gerenciamento de contatos, inspirada no design do eaipago.com e outras plataformas modernas.

![React](https://img.shields.io/badge/React-19.1.0-blue)
![Framer Motion](https://img.shields.io/badge/Framer%20Motion-Animations-purple)
![Lucide React](https://img.shields.io/badge/Lucide-Icons-green)
![Vite](https://img.shields.io/badge/Vite-Build%20Tool-yellow)

## ✨ Características Principais

### 🎨 Design Moderno
- **Glassmorphism**: Efeitos de vidro com blur e transparência
- **Gradientes Dinâmicos**: Paleta de cores moderna com gradientes suaves
- **Animações Fluidas**: Transições e animações usando Framer Motion
- **Background Animado**: Fundo com efeitos visuais dinâmicos
- **Responsivo**: Design adaptável para todos os dispositivos

### 🚀 Funcionalidades Avançadas
- **Modal Inteligente**: Formulário de contato em modal com animações
- **Busca em Tempo Real**: Sistema de busca instantânea
- **Filtros Múltiplos**: Filtros por usuário, cidade e estado
- **Estatísticas Visuais**: Cards com estatísticas dos contatos
- **Validação de CEP**: Integração com API ViaCEP para preenchimento automático
- **Feedback Visual**: Notificações toast elegantes
- **Persistência Local**: Dados salvos no localStorage

### 🎯 Experiência do Usuário
- **Micro-interações**: Hover effects e animações de clique
- **Estados Visuais**: Indicadores de loading, sucesso e erro
- **Empty States**: Telas vazias com call-to-actions
- **Filtros Ativos**: Visualização dos filtros aplicados
- **Confirmações**: Diálogos de confirmação para ações destrutivas

## 🛠️ Tecnologias Utilizadas

- **React 19.1.0** - Framework principal
- **Framer Motion** - Animações e transições
- **Lucide React** - Ícones modernos
- **React Toastify** - Notificações
- **Vite** - Build tool e dev server
- **CSS3** - Estilização avançada com variáveis CSS

## 📦 Instalação e Execução

```bash
# Clone o repositório
git clone [url-do-repositorio]

# Navegue para o diretório
cd minha-agenda-react

# Instale as dependências
npm install

# Execute em modo de desenvolvimento
npm run dev

# Build para produção
npm run build
```

## 🎨 Design System

### Paleta de Cores
- **Primary**: Gradiente azul-roxo (#667eea → #764ba2)
- **Success**: Gradiente azul-ciano (#4facfe → #00f2fe)
- **Warning**: Gradiente laranja-pêssego (#ffecd2 → #fcb69f)
- **Danger**: Gradiente rosa-lilás (#ff9a9e → #fecfef)

### Tipografia
- **Fonte**: Inter (Google Fonts)
- **Pesos**: 300, 400, 500, 600, 700, 800

### Componentes
- **Glass Cards**: Efeito glassmorphism
- **Modern Buttons**: Gradientes com animações
- **Form Elements**: Inputs com estados visuais
- **Modal System**: Modais animados e responsivos

## 🔧 Funcionalidades Técnicas

### Gerenciamento de Estado
- useState para estados locais
- useEffect para persistência
- useMemo para otimização de performance

### Animações
- Framer Motion para todas as animações
- Variantes de animação reutilizáveis
- Stagger animations para listas
- Micro-interações em botões

### Responsividade
- Mobile-first approach
- Breakpoints otimizados
- Grid adaptável
- Componentes flexíveis

### Performance
- Lazy loading de componentes
- Memoização de cálculos
- Otimização de re-renders
- Bundle splitting
